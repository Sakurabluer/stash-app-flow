# Privacy

Stash Flow does not operate a backend service and does not collect analytics,
telemetry, advertising identifiers, contacts, location, or media files.

The app connects directly from the user's device to Stash Server addresses
configured by the user. Server URLs and local favorites are stored in the
app's private preferences. API keys are stored with Android secure storage and
are sent only to the configured Stash Server when required for API or media
requests.

The app does not upload the user's Stash data to the project maintainer. The
privacy and security of a configured Stash Server remain the responsibility of
that server's operator.

Uninstalling the app or clearing its data removes locally stored server
profiles and favorites. Users should not include API keys, private server
addresses, or personal media information in public bug reports.
